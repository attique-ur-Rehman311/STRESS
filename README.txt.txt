Requirements:
- Python 3.x
- Django 6.0.3
- Install packages using:
  pip install -r requirements.txt

Run Project:
1. Open Command Prompt.
2. Go to the project folder.
3. Run:
   python manage.py runserver
4. Open:
   http://127.0.0.1:8000/
